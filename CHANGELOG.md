# Changelog

## 0.1.0 - 2026-09-03

- Synchronized `ProteusMCMScript.psc` with the source bundled in official Proteus 3.4.0.
- Replaced the state-option-only MCM update call in all twelve active hotkey branches with SkyUI's indexed keymap API.
- Added locked, deterministic double compilation with Caprica 0.3.0.
- Added PEX decompilation verification and a deterministic MO2-ready package.

This version is a test candidate and has not yet completed in-game acceptance.
